# DIGITEM-MX Website - Astro Production V1.0

Proyecto matriz DIGITEM-MX reconstruido en Astro, integrando la vertical DIGITEM-MX Salud.

## Rutas incluidas

- `/` — Matriz DIGITEM-MX
- `/salud` — Landing DIGITEM-MX Salud
- `/salud/dentista` — Placeholder comercial para dentistas
- `/salud/psicologia` — Placeholder comercial para psicología
- `/demo/dentista` — Placeholder demo dentista
- `/demo/psicologia` — Placeholder demo psicología

## Correr localmente

```bash
npm install
npm run dev
```

Abrir:

```text
http://localhost:4321
http://localhost:4321/salud
```
